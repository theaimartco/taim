# TAIM 0.15.0-rc.1

A release candidate: the code for 0.15.0, offered for testing before the
final release. It becomes 0.15.0, unchanged, once the remaining gates
pass; a fix found during testing makes an rc.2.

## Who can use it now

| Use | Ready? |
|---|---|
| Desktop applications on Linux (X11, Wayland) | Usable now: every automated check passes, and the showcase and examples were run and inspected on a virtual X11 display (Xvfb) with a software GPU. Physical displays and GPUs have not been signed off. |
| Android applications | For internal and beta testing (Play Console internal or closed testing). Not yet run on a device. |
| Windows, macOS | Built from the same code but not exercised in this release cycle. |
| iOS, Web | Not supported. |

## Upgrading from 0.14 or 0.15.0-dev

The application model changed: see `CHANGELOG.md` under "Breaking", and
`examples/counter`, `examples/mobile_shell` and `examples/liquid` for the
view API. `taim-new` writes a working starting point.

## Verifying it yourself

```sh
bash scripts/release/check.sh ~/evidence/check          # exit 0 means complete
bash scripts/qa/android-device-check.sh ~/evidence/phone1  # with a phone connected
```

Exit code 3 from `check.sh` means a step was skipped (no NDK, or no GPU
adapter for the GPU tests) and the check is not complete.
